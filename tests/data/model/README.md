# Model fixtures

`BoxAnimated.glb` and `RiggedSimple.glb` are from the Khronos glTF Sample Assets
(https://github.com/KhronosGroup/glTF-Sample-Assets), CC BY 4.0 — © Cesium.
BoxAnimated carries node TRS animation (a lid that rotates and translates); RiggedSimple is
a two-joint skinned cylinder with a LINEAR animation.
